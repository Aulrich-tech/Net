Bonifacio

TASK 7 — RIPv1 on Aguinaldo
Aguinaldo — RIPv1 is classful; 172.16.x.x all summarize to Class B
Aguinaldo(config)# router rip Aguinaldo(config-router)# network 172.16.0.0 Aguinaldo(config-router)# network 172.16.8.0 Aguinaldo(config-router)# network 172.16.32.0 Aguinaldo(config-router)# exit ! RIPv1 auto-summarizes all 172.16.x.x → distributes to neighbors
